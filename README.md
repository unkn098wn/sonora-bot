# SonoraAuthBot — Telegram-бот авторизации Sonora Music

Официальный Telegram-бот для безопасной авторизации и подтверждения аккаунтов пользователей приложения Sonora (Windows, Android, Web).

## 🚀 Возможности
- **Одноразовые 6-значные коды (OTP):** генерируются криптографически надёжным генератором с автоматическим сроком действия 5 минут.
- **Интерактивные Deep-links:** переход по ссылке `https://t.me/SonoraMusicBot?start=auth_<sessionId>` моментально генерирует код и показывает удобную кнопку для возврата в Sonora (`sonora://auth?code=...`).
- **Клик для копирования:** код оформлен тегом `<code>`, копируется в один клик.
- **Раздача установщиков в боте:** команда `/download` (или `/app`) выдаёт прямые ссылки на Windows Setup (.exe), Windows Portable (.zip) и Android (.apk).
- **Обзор возможностей:** команда `/features` подробно описывает 18 площадок, установку своего видео на фон, Zen Stage и DSP студию.
- **Встроенный HTTP API Gateway (порт 8088):** для проверки кодов приложением Sonora и прямая раздача релизных файлов через `/downloads/`.

## 🛠️ Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Установите токен от `@BotFather`:
   ```bash
   set SONORA_BOT_TOKEN=1234567890:ABC-DEF_GHIJ...
   ```
3. Запустите:
   ```bash
   python bot.py
   ```
   или дважды кликните `run_bot.bat` на Windows.
